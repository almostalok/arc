# ARC Placement Command Center & Pulse Specification

---

## 1. ARC Placement Command Center
- **Institutional CRM**: Tiered directory of hiring partners (Super Dream, Dream, Tier 1, Tier 2).
- **Rule-Based Eligibility Engine**: Automatically screens candidates based on multi-variable logic (CGPA, active backlogs, department, graduation year, attendance threshold).
- **Application Pipeline Kanban**: Tracks candidates across 8 standard sequential stages (`Eligible` → `Applied` → `Shortlisted` → `Online Assessment` → `Technical Round` → `HR Round` → `Selected` → `Placed`).
- **Interview Scorecards**: Structured multi-dimensional evaluation (Technical, Communication, Problem Solving, Culture Fit, Overall Recommendation).

---

## 2. ARC Pulse — Talent Intelligence
- Converts scattered student activity into structured, evidence-backed talent intelligence.
- **Radar Pillars**: Academics, Coding, Development, Communication, Leadership, Career Readiness.
- **Transparent Signal Models**: Weighted composite index based on verified artifacts.
