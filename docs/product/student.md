# ARC Student OS — Product Specification

---

## 1. Vision & Purpose
The student enters ARC once and holds a unified identity powering:
`Academics → Attendance → Skills → Projects → Experience → Resume → Opportunities → Applications → Interviews → Placement`

## 2. Core Workflows
- **Attendance Intelligence**: Displays current attendance and calculates "How many more classes can I safely miss without dropping below 75%?".
- **Academics & Transcripts**: Live semester GPA trends, credit totals, and examination timetables.
- **Talent Graph**: Verified skills linked to evidence (GitHub repositories, LeetCode ratings, internships, certifications).
- **Placement Pipeline**: Transparent view of all active campus drives, deterministic eligibility checks, application timeline, and interview schedules.
- **Official Resume Export**: Generates authentic, verifiable resume documents directly from the institutional graph.
